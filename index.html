Proof-of-Work Scoring Methodology

ProofMatch computes a deterministic 0–100 score across five weighted dimensions without double-counting repeated keywords:

  • Technical Skill Coverage (35%): Share of job-required skills backed by repository evidence, weighted by evidence strength.
  • Project Evidence Quality (25%): Depth of proof—primary language + topics + multi-repo reinforcement score higher than isolated README mentions.
  • Repository Relevance (20%): How closely the candidate's repositories align with the target role's core stack and responsibilities.
  • Activity & Maintenance (10%): Recency of repository updates and sustained portfolio activity.
  • Documentation Quality (10%): Presence of descriptions, topics, and substantive READMEs (architecture, setup, testing notes).

Important: Metadata and README text are useful evidence signals, not definitive proof of production coding proficiency.
